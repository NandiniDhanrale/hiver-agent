# Hiver Support Agent Data

## Directory Structure

- `raw/` - Original twcs.csv from Kaggle (not committed to git)
- `processed/` - Derived development data from conversation reconstruction
- `golden/` - Golden evaluation set (manually labeled)
- `samples/` - Small sample files for testing

## Raw Data

Place `twcs.csv` from the Kaggle dataset here:
```
data/raw/twcs.csv
```

Do NOT commit the full Kaggle CSV to git.

## Processed Data

Generated by running:
```bash
python scripts/prepare_data.py
```

Files:
- `dev_cases.json` - Development pool cases
- `golden_candidates.json` - Candidates for golden set
- `conversations.json` - Sample reconstructed conversations
- `stats.json` - Data preparation statistics

## Golden Set

The golden evaluation set must be HUMAN LABELED.

1. Generate candidates:
```bash
python -m scripts.create_golden_candidates
```

2. Label using the terminal tool:
```bash
python -m scripts.label_golden
```

3. The output is `golden/golden_set.csv`

### Important Rules

- The golden set must NOT be used for:
  - Retrieval index
  - Few-shot examples
  - Prompt development
  - Threshold tuning
  - Taxonomy construction
- Human labels are the ground truth
- AI-generated labels must NEVER be passed off as human labels
